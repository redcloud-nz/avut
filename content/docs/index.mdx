# AVUT Documentation

Welcome to the documentation for **AVUT** — Assorted Vaguely Useful Tools. These
guides explain how to use the app, from signing in for the first time through to
the day-to-day work in each module.

## Where to start

- **New here?** Read [Getting Started](/docs/getting-started) for a tour of the
  basics — organizations, modules, and navigation.
- **Looking for a specific feature?** Jump to its section in the sidebar. Each
  module of AVUT has its own section.
- **Managing your login or profile?** See [Your Account](/docs/account).
