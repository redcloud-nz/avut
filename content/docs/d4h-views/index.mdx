# D4H Views

D4H Views shows data from your organization's **D4H** account inside AVUT,
read-only. It's there so you can reference D4H members, equipment, and activity
without switching tools.

## Requirements

This module only works when your organization has configured a D4H access token.
If you don't see any data, ask an admin to check the D4H connection in settings.

## What you can see

The available views mirror the D4H resources your token has access to — members,
teams, and equipment among them. Nothing here changes D4H; edits still happen in
D4H itself.
