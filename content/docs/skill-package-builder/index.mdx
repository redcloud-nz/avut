# Skill Package Builder

A **skill package** is a reusable, versioned set of skills and skill groups that
organizations can subscribe to from their Skill Track catalogue. The Skill
Package Builder is where authors create and maintain them.

## Key ideas

- A package has a **library** of skill groups and skills, edited here.
- Publishing a **version** makes that snapshot available to subscribers.
- Subscribing organizations pull a package into their catalogue and can apply
  **overrides** without changing the source.

## Roles

Authoring requires the `skill-package-author` role.
