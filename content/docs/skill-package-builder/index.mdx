# Skill Package Builder

A **skill package** is a set of skill groups and skills that other
organizations can use from their Skill Track catalogue. The Skill Package
Builder is where authors create and maintain them.

## Key ideas

- A package is simply its set of **skill groups and skills**, edited here.
- **Publishing** a package makes it appear in the Skill Track catalogue of other
  organizations.
- Packages aren't versioned — the published package always reflects its current
  state.

## Roles

Authoring requires the `skill-package-author` role.
