# Checks

**Recent Skill Checks** lists every check dated in the last month, from
sessions and from outside them, with its result, session, date and assessor. A
session's checks show here whether or not the session has been approved.

Skills Assessors and Skills Admins can add checks. Skills Reporters can view the
list.

## Adding a check outside a session

**Add Check** records a single check outside any session — an informal
observation, say, that you want on record without setting up a whole session,
or a result from before your organisation used AVUT. Pick the person, the skill
and a result, and add notes if you like.

**Date checked** is today unless you pick an earlier day. Reports date the
check, and work out when it expires, from that day. A check dated more than a
month ago is saved, but doesn't show under **Recent Skill Checks**.

You're always recorded as the assessor, so you need a
[person record linked](/docs/admin/user-vs-person) to your account.

A check added here belongs to no session, so there's no review or approval: it
counts in the [reports](/docs/skill-track/reports) as soon as you add it. When
a result should be reviewed before it counts, record it in a
[session](/docs/skill-track/sessions) instead.
