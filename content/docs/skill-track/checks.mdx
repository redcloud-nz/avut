# Checks

The **Checks** page is a flat, organisation-wide log of recently recorded
skill checks (the last month), separate from any one session. It's for
recording an **ad-hoc** check — an informal or historical observation you want
on record without setting up a whole session.

To record one: pick a person, pick a skill, pick a result, and add notes if you
want. You're always the assessor for a check you record here.

<Callout>
  Ad-hoc checks are recorded immediately — there's no review or approval step, unlike checks
  recorded inside a session.
</Callout>
