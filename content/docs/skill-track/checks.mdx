# Checks

**Recent Skill Checks** lists every check dated in the last month, from
sessions and from outside them, with its result, session, date and assessor. A
session's checks show here whether or not the session has been approved.

Skills Assessors and Skills Admins can add checks. Skills Reporters can view the
list.

## Adding a check outside a session

**Add Check** records a single check outside any session — an informal
observation, say, that you want on record without setting up a whole session.
Pick the person, the skill and a result, and add notes if you like.

You're always recorded as the assessor, so you need a
[person record linked](/docs/admin/user-vs-person) to your account. The check is
dated today; you can't back-date it.

<Callout type="warning">
  A check added here belongs to no session, so it's never reviewed or approved — and today it
  doesn't count in the [reports](/docs/skill-track/reports). To put a result on someone's record,
  record it in a [session](/docs/skill-track/sessions) and approve the session.
</Callout>
