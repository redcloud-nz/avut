# Users vs Personnel

Admin has two separate lists — **Users** and **Personnel** — for two related
but distinct concepts.

## User

A **user** is a login account: an email address, a password (or social
sign-in), and a session. It's the thing someone signs in with, and one user
can belong to more than one organisation.

## Person

A **person** is a personnel record scoped to a single organisation — a name,
contact details, and whatever else your organisation tracks about its people.
A person can exist with no login attached at all, which is normal for tracking
someone who isn't given app access.

## How they connect

Within an organisation, a user can be linked to at most one person, and a
person to at most one user — but neither side requires the other:

- A person with no linked user is on the roster but can't sign in.
- A user with no linked person can sign in (for example, an admin-only
  account) but won't appear in personnel-based screens like sessions or
  reports.

There are four ways to link them:

- **Invite from the person record.** **Invite to AVUT**, on a person's page in
  **Personnel**, emails them an invitation. When they accept it, their account
  is linked to that record. If the email already belongs to a member of your
  organisation, the dialog offers **Link Account** instead, which links them
  straight away.
- **Link from the person side.** **Link to user**, in a person's menu, attaches
  an existing member's account. **Unlink from user** removes the connection.
- **Link from the user side.** **Link person**, on a user's page in **Users**,
  attaches a person record that isn't linked yet. **Unlink** removes it.
- **Link automatically by email.** **Organisation Settings → Personnel** has two
  switches. **Link on invitation accept** links someone who accepts any
  invitation to the person record with the same email, if there is one. **Link
  when a person is added** links a new person record to the existing member with
  the same email. Neither switch ever adds someone to the organisation: only an
  invitation does that.

Unlinking never deletes either record.

<Callout>
  Several places in the app — recording a skill check yourself, for example — require you to have a
  linked person before you can act. If you see a warning about a "linked personal record," this is
  what it means.
</Callout>
