# Admin

The Admin module is where an organisation's **owners** and **admins** manage who
has access and how the organisation is set up. It's always available — every
organisation has it.

## What's here

- **Personnel** — the people records for your organisation. A person record can
  exist without a login attached — see
  [Users vs Personnel](/docs/admin/user-vs-person) for how the two connect.
- **Users** — accounts that can sign in, and the role each one holds.
- **Teams** — groupings of people used across other modules.
- **Invitations** — outstanding invites to join the organisation.

## Roles

Roles decide what someone can do. `owner` and `admin` can manage the
organisation; `member` has everyday access; the remaining roles
(`i3-editor`, `skills-assessor`, `skill-package-author`) grant extra rights in
specific modules.
