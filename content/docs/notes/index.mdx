# Notes

Notes is a simple rich-text notebook for your organisation — meeting minutes,
running checklists, reference material, anything worth keeping in one shared
place.

## Working with notes

- Create a note and give it a title. The editor supports headings, lists,
  links, and basic formatting.
- Notes are visible to members of your organisation according to your role.
- Changes save as you type.
