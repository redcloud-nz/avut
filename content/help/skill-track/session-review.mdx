**Review** is where a Skills Admin approves a session. Anyone else who can see
the session gets the same page, read-only.

The tiles at the top count **Unique checks** (two assessors checking the same
person and skill count once), the **Personnel** and **Skills** with checks, and
**Coverage**: the share of the session's person and skill pairs that have a
check. The menu (⋮) can leave unassessed personnel or skills out of these
figures.

- **Conflicts** lists each person and skill with more than one check.
  **Resolve** picks the one to include, or excludes them all.
- **Personnel** and **Skills** show each one's checks and coverage. Click one
  to see its checks, untick any you want to exclude, then **Save**. Checks in a
  conflict can't be changed there; settle them with **Resolve**.

Every check is included unless you exclude it. Each **Save** is kept straight
away, so you can come back to a review later.

**Approve** is disabled while the session has no checks, or until every
conflict is resolved. Approving keeps the
included checks, which then count in reports, and locks the session. **Reopen**
unlocks it so checks can be recorded and reviewed again; until it's approved
again, its results leave the reports.
