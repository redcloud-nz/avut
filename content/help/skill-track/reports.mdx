All four reports summarise the same competency data, sliced differently. Each
one opens a dialogue to pick its scope (a person, a team or a skill) before
showing results.

Every report uses the same status for a person and skill:

- **Current** — competent, and still within the skill's currency window.
- **Expired** — was competent, but the currency window has lapsed.
- **Not Competent** — the most recent result wasn't a pass.
- **Not Assessed** — no check on record.
