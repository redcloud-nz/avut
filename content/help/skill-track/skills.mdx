**Skills** lists every skill your organisation can assess, in one table: the
skills of each package you subscribe to, with the group and package it belongs
to. It's the same set the session skill picker uses. A package its author has
withdrawn drops out until it's published again. A skill marked **Archived** is
still listed here, but the reports and the package's page leave it out.

**Frequency** is how often the skill should be reassessed. A check older than
that counts as expired in the reports. **None** means a check never expires.

Search by skill, group or package name, or filter by **Package**. Open a
package to see its groups and skill descriptions in the **Catalogue**.

To add skills, subscribe to another package in the **Catalogue**. The skills
themselves are set by each package's author, so they can't be changed here.
