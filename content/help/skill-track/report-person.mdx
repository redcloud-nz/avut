Pick a person to see their status on every skill your organisation subscribes
to, grouped by package and skill group, with the date each was last checked.
**Change scope** picks someone else. Only active personnel are listed.

The status comes from the person's most recent check in an approved session, so
a newer fail replaces an older pass. Checks added on the **Checks** page don't
count.

The menu (⋮) can show **Only Gaps** (every skill that isn't Current), each
skill's description, and a count of each status under the title.

Click a skill's name for its description and reassessment interval. Click a
status for the check behind it: the result, when it was assessed and when it
expires, who assessed it, and any notes.
