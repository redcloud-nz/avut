Pick a skill to see every active person's status for it, with the date each was
last checked. Use it to answer "who can do this?". The **Team** list in the same
dialog narrows it to one team; it starts on **Whole Organisation**.

The personnel who need attention come first: **Not Competent**, then **Expired**,
then **Not Assessed**, then **Current**.

**Change scope** picks another skill or team. The menu (⋮) can show a count of
each status under the title. Click a status for the check behind it: the
result, when it was assessed and when it expires, who assessed it, and any
notes.

A status comes from the person's most recent check in an approved session.
Checks added on the **Checks** page don't count.
