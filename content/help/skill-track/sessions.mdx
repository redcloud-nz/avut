**Skill Check Sessions** lists your organisation's sessions, most recently
updated first, with each one's team, assessors and status. Filter the **Team**
column to see one team's sessions, or the ones with **No team**. A session is
**Draft** while it's being worked on, and **Approved** once a Skills Admin has
approved it.

In a team, the list shows that team's sessions, new sessions belong to the team,
and there is no Team column or field.

**New Session** starts one. The name, times and notes are all optional: a blank
name takes the next session number, and a new session runs all day today. Pick
the date, then turn on **Multiple days** to add an end date, and turn off
**All day** to give the session a start and end time, in 15-minute steps. With
both, the session runs from the start time on the first day to the end time on
the end date. On a single day, an end time earlier than the start runs into the
next day. Times are in your organisation's time zone, which the picker shows.

A session can belong to a team. Choosing one at creation adds the team's
active members to the session's personnel, and you can still change them
afterwards. Changing the team later doesn't touch the personnel.

Every check recorded in the session carries the session's start, not the time it
was entered, so set the start to when the assessing happened.

Creating a session makes you its first assessor, so you need a person record
linked to your account. Skills Assessors and Skills Admins can create sessions;
Skills Reporters can only view them.

Open a session to choose its personnel and skills, record results, and review
it.
