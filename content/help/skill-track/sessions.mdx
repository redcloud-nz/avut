**Skill Check Sessions** lists your organisation's sessions, most recently
updated first, with each one's assessors and status. A session is **Draft**
while it's being worked on, and **Approved** once a Skills Admin has approved
it.

**New Session** starts one. The name, times and notes are all optional: a blank
name takes the next session number, and a new session runs all day today. Pick
the start date, then **+ Add end date** for an all-day session that runs over
several days, or **+ Add time** to give it a start and end time instead, in
15-minute steps. The × on the end date makes the session a single day again. An
end time earlier than the start runs into the next day; the × on the end time
leaves the session with no end, and **Remove time** makes it all day again. Times are in your organisation's time zone, which the picker
shows.

Every check recorded in the session carries the session's start, not the time it
was entered, so set the start to when the assessing happened.

Creating a session makes you its first assessor, so you need a person record
linked to your account. Skills Assessors and Skills Admins can create sessions;
Skills Reporters can only view them.

Open a session to choose its personnel and skills, record results, and review
it.
