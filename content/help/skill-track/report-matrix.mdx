Pick a team, or **Whole Organisation**, to see skills down the side, grouped by
package and skill group, and the team's active members across the top. Each
cell shows that person's status for that skill.

Click a skill's name for its description and reassessment interval. Click a
cell for the check behind it: the result, when it was assessed and when it
expires, who assessed it, and any notes.

**Change scope** picks another team. The menu (⋮) can show each skill's
description and a count of each status under the title.

A cell's status comes from that person's most recent check in an approved
session. Checks added on the **Checks** page don't count.
