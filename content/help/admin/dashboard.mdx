The Admin module is where your organisation's **owners** and **admins** manage
who's in it and how it's set up. Every organisation has it.

Each link opens one area. You only see the links your roles allow.

- **Invitations**: invite people to sign in, and track the invitations sent.
- **Organisation**: the organisation's name and slug, and its D4H link if it
  has one.
- **Organisation Settings**: how person records link to accounts, how long the
  Rubbish bin keeps things, integrations and modules.
- **Personnel**: a person record for everyone your organisation tracks, with or
  without a login.
- **Teams**: groupings of personnel, optionally kept in sync with D4H.
- **Users**: the accounts that can sign in here, and the roles each one holds.
- **Rubbish**: deleted records, until they're purged. It only shows if you can
  delete something.

**Personnel** and **Users** are separate lists. A person is a roster record, a
user is a login, and an admin can link the two.
