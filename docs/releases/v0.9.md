## v0.9 (Philomel)

A large release: person↔user account linking, deeper D4H team integration, a
reworked team membership experience, the first cut of end-user documentation,
and a wide pass of smaller fixes and refactors.

### Highlights

- **Person↔user account linking** — a person record and a user account can now
  be linked automatically (on invitation accept, or when emails match) or
  manually from the person record's own invite flow, with `Person.email`
  normalized to lowercase to make matching reliable.
- **D4H linking & preview-then-apply team sync (Phase 1)** — teams can be
  linked to a D4H team via sidecar link tables, with a preview-then-apply sync
  flow, an admin D4H integration card, and D4H-aware team menu actions
  (link/unlink/sync, org metadata sync).
- **Team membership rework** — the team roster now lives on Kaga, with a
  dedicated team-membership detail page (D4H status/source badges, inline
  Person/Team links, membership timestamps) replacing inline roster actions.
- **Skill package import/export** — packages can be exported to `.json` and
  imported across instances, replacing the old bundled-library-only flow.
- **End-user documentation site** — a new `/docs` section with a glossary,
  per-page "Key Terms" callouts, screenshots, and an in-app `?help` sheet
  available from admin and skill-track pages.
- **Public site refresh** — shared header/footer across `/`, `/docs`,
  `/auth`, and `/policies`; rewritten privacy policy and terms of service; a
  new `/tools` page listing tools by module.
- **Kaga table improvements** — reworked table header/toolbar, per-column
  sort/filter menus, and a "Show query" debug option.
- **Outbound email safety** — `sendEmail` now redirects every send outside
  production to Resend's sink, so the dev database's real email addresses can
  never be mailed by accident.
- **en-NZ spelling** — a lint guardrail plus a sweep of user-facing copy to
  New Zealand English spelling.
- Numerous smaller fixes: mobile breadcrumb dropdown, persisted sidebar
  collapse state, Suspense-boundary/Cache-Components cleanup across the
  authenticated layout, and dependency upgrades closing several dependabot
  alerts.
