## v0.9.2 (Philomel)

Small patch: one crash fix and a build-display change.

### Highlights

- **`createOrganization` no longer times out on the default-settings inserts**
  — the mutation spread one `organizationConfig.create()` per default
  settings leaf (~20+ rows) into the same batched `$transaction` as the
  organization/owner/log-event creates, bounded by Prisma's default 5000ms
  batch timeout. A production call hit `P2028` outright. The config rows are
  now written with a single `createMany`, cutting the batch to a handful of
  statements regardless of how many settings leaves exist. (#168)
- **Non-production environments show branch + commit instead of a build
  counter** — the old counter required a workflow that commits straight to
  `integration`, which branch protection now blocks. Dev/preview builds now
  display the branch name and short commit SHA instead (sourced from
  Vercel/GitHub env vars, with a git fallback for local dev).
