## v0.8.1 (Philomel)

Hotfix for Google sign-in on production.

### Highlights

- **Fixed Google OAuth on production** — `auth.ts` built its `baseURL` from
  `NEXT_PUBLIC_BASE_URL`, an env var that was never actually set, so it fell
  back to `http://localhost:3000` and Google blocked the callback
  (`Access Blocked`, `redirect_uri=http://localhost:3000/...`). Now reads
  `BETTER_AUTH_URL`, which was already configured correctly for every
  environment.
